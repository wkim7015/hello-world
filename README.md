# Quantitative Strategy Backtester for KOSPI & KOSDAQ

This repository contains a quantitative long-only strategy designed to operate on the top 150 KOSPI and top 30 KOSDAQ stocks.

## Goal
To develop a robust strategy taking into account realistic 0.6% friction costs on selling, while attempting to target high CAGR, low MDD, and low beta against KOSPI.

## Files
- `backtester.py`: Vectorized backtesting framework including calculation of Alpha and Beta.
- `generate_strategy.py`: The strategy generation loop containing over 100 iterations of random hyperparameter search (combining Momentum, Inverse Volatility, and varying Market Regime Filters) to find the best configuration satisfying the constraints.
- `benchmarks.csv`: Reference benchmark data for KOSPI, KOSDAQ, and S&P500.
- `trades.csv`: List of all buy and sell trades generated by the best strategy.
- `portfolio_values.csv`: The portfolio value over time (indexed to 1.0 at start).
- `best_weights.csv`: The daily target weights of the portfolio for the duration of the backtest.

## Output Metrics
The final best strategy metrics are printed out during execution and verified against real data over a 10-year period.

### How to Use
1. **Download Data**: Run `python download_data.py` to authenticate with KRX and fetch the 10-year OHLCV, Fundamental, and Institutional volume data for the KOSPI 150 and KOSDAQ 30.
2. **Generate Strategy**: Run `python generate_strategy.py` to evaluate 100 random strategy permutations against the data in `data/`. The script will output `trades.csv`, `portfolio_values.csv`, and `best_weights.csv`.
